# Guadeloupe-electricity-dashboard

This repository contain a Quarto dashboard presenting an overview of Guadeloupe archipelago electricity system.
The dashboard focus on electricity generation trends from 2016 to 2024.

## Dashboard content

The dashboard includes:
- Installed capacities of electricity generation
- Electricity generation trends per power plants
- CO2 emissions from electricity generation
- Hourly time series of electricity generation

## Technical details

Built with Quarto using python and altair.
